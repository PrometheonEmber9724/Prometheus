# Prometheus One — Judge Quick Start

## Fastest route

1. Run `setup_windows.bat` once.
2. Run `run_windows.bat`.
3. Choose **Open Judge Demo** on the login screen.

Manual credentials:

```text
judge@prometheus.demo
PrometheusDemo26!
```

No API keys, external database or cloud account is required for the core demo.

## What to test

**1. Marketplace → Deal Room**  
Open an opportunity and inspect its thesis, risks, use of funds, scenario analysis and capital timeline.

**2. Portfolio**  
Review the seeded diversified portfolio and rules-based Portfolio Intelligence.

**3. Secondary Market**  
Inspect indicative bids and executable asks. Listed units are reserved and buyer/seller cash and ownership settle atomically.

**4. Liquidity Intelligence — core V7 innovation**  
Open a Liquidity Passport and change the proposed listing price. Confirm that:

- Liquidity Score changes
- 7 / 14 / 30-day sale probabilities change
- Expected time-to-sale changes
- Pricing guidance changes
- “Why did the score change?” updates
- Factor explanations remain visible

Then inspect the Portfolio Liquidity Stress Test, Liquidity Ladder and Transparency Centre.

## What makes Prometheus One different

**Most investment platforms help investors get in. Prometheus One also helps them understand the path back out.**

The app combines fractional private-market access, Deal Intelligence, a structured secondary market and explainable predictive Liquidity Intelligence.

## Important disclosure

All opportunities, money, KYC, bids, historical listings and model data are simulated. Forecasts are decision-support estimates only and do not guarantee liquidity or constitute financial advice.


## Session controls
Use **Logout** from the desktop sidebar, mobile top bar, or Profile / KYC / Security screen to return to the sign-in screen.
